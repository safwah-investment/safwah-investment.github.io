# صفوة | منصة الاستثمار والشراكات والحوكمة

**الإصدار 2.0 — مشروع مستقل جاهز للنشر على GitHub Pages**، بواجهة عربية RTL متجاوبة، مناسب لسطح المكتب والهواتف، ويدعم التثبيت كتطبيق ويب PWA على الأجهزة المتوافقة.

![Safwah](assets/favicon.svg)

## ماذا يفعل البرنامج؟

1. **إدارة ملاك صفوة:** المساهمون، نسب الملكية المباشرة، إيضاح الملكية غير المباشرة في مستوى واحد (Look-through)، المساهمة والدور.
2. **إدارة ملاك الأصول:** سجل مستقل لملاك العقارات/الأصول من غير مالكي شركة صفوة.
3. **الفرص الاستثمارية والعقارية:** معلومات العروض، مراحل الصفقة، نسبة العمولة والإحالات وملاك الأصول والوثائق والملاحظات.
4. **قرارات الملاك:** التصويت المرجّح بناء على لقطة نسب الملكية يوم إنشاء القرار؛ ملاحظة أن المحضر الوصفي ليس تصويتًا رسميًا موثقًا.
5. **محاكاة المستثمرين:** ضخ نقدي في الشركة (Cash-in)، شراء حصة حالية (Cash-out)، والمزيج بينهما، مع فصل المدفوع للشركة عن المدفوع للبائع.
6. **استوديو الشراكات (جديد):** ستة مسارات:
   - مشروع تشغيلي.
   - صفقة تجارية.
   - مشروع ناشئ بنماذج وزن استرشادية للمساهمات.
   - دخول مستثمر جديد إلى كيان قائم.
   - مضاربة بتوزيع أرباح متفق عليه، دون تحويل الأرباح إلى ملكية تلقائية.
   - إعادة تنظيم شراكة قائمة.
7. **داخل كل ملف شراكة:** سبع مراحل: التعريف، الأطراف، الالتزامات والدفعات، الحصص والتقييم، الحوكمة، البدائل والاعتماد الداخلي، التقدير المالي وخطة التنفيذ والتقرير.
8. **المخرجات:** تصدير Word DOCX قابل للتحرير، تقرير HTML، طباعة PDF عبر المتصفح، نسخ JSON للملف الواحد أو كامل مساحة العمل، وتصدير CSV.
9. **التجربة:** مثال تعليمي جاهز، مساعد إرشادي يعمل بقواعد حسابية، وحفظ تلقائي محلي.

## التشغيل

بعد فك الضغط، افتح المجلد في طرفية:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/` في المتصفح. لا تتطلب الحسابات الأساسية خادمًا أو مفتاح API، ولا يتصل التطبيق بخدمة ذكاء اصطناعي.

> فتح `index.html` مباشرة قد يشغّل معظم الشاشة محليًا، لكن وضع PWA/Service Worker يحتاج **HTTPS أو localhost**.

## النشر على GitHub Pages

1. أنشئ مستودعًا باسم تختاره مثل `safwah-partnerships` تحت حساب صفوة الرسمي.
2. ارفع **المحتويات الموجودة داخل هذا المجلد** إلى جذر المستودع (بما فيها `index.html` وملفات `.js` و`.css` ومجلد `assets`).
3. من `Settings → Pages` اختر `Deploy from a branch`، الفرع `main`، والمجلد `/root`.
4. انتظر نشر الموقع وافتح الرابط الذي يظهر في إعدادات Pages.
5. يمكن تثبيت التطبيق على الهاتف من قائمة المتصفح عبر `إضافة إلى الشاشة الرئيسية`. تظهر نافذة تثبيت مباشرة في بعض متصفحات Android/Chrome فقط.

**رابط المشروع المنشور:** https://safwah-investment.github.io/partnerships/ — الملفات تحت `partnerships/` في مستودع `safwah-investment.github.io`.

**تنبيه:** نشر ملفات البرنامج لا ينشئ قاعدة بيانات مركزية أو حسابات مستخدمين.

## هيكل المجلد

| ملف | مهمته |
|---|---|
| `index.html` | واجهة التطبيق ولوحة التحكم والتنقل بين الأقسام |
| `styles.css` | الهوية الأساسية المتجاوبة لصفوة |
| `core.js` | حسابات ملاك الشركة والتصويت والعمولات والمحاكاة |
| `app.js` | بيانات الملاك والفرص وسجلات الشركة والحفظ والاستيراد |
| `partnership-core.js` | محرك حساب الشراكات والجهد والاستثمار والبدائل والسجل المالي |
| `partnerships.js` | واجهة مراحل الشراكات والتقارير والمساعد الإرشادي |
| `partnerships.css` | تنسيق استوديو الشراكات وواجهات الجوال |
| `word-export.js` | إنشاء مستندات DOCX عربية دون مكتبات خارجية |
| `manifest.webmanifest` / `sw.js` / `pwa.js` | تثبيت التطبيق وتخزين ملفات التشغيل الثابتة لفتحها دون اتصال بعد أول زيارة |
| `assets` | الأيقونات والهوية الأولية |
| `tests` | اختبارات حسابية وتفاعلية |

## الاختبارات

```bash
node --test tests/*.test.cjs
```

اجتازت النسخة **31 اختبارًا حسابيًا** شملت نماذج رأس المال، فروق الملكية، المضاربة، الدفعات، التصويت، معادلات المحاكاة والسيناريوهات.

التجربة التفاعلية بواسطة Chromium المحلي (يتطلب Python Playwright ومتصفح Chromium):

```bash
python tests/browser_checks.py
```

اختُبرت خمسة مسارات تفاعلية، بينها الاستثمار المختلط والمضاربة، وتصدير Word وحفظ الملفات واختبار العروض 320/390/768/1280 بكسل. فُتح مستند Word التجريبي بنجاح عبر أداة عرضه.

## تخزين الملفات والخصوصية

- التخزين الحالي `localStorage` داخل المتصفح على هذا الجهاز فقط. يتم حفظ سجلات الشراكات في حقل `partnerships` ضمن مساحة عمل صفوة نفسها، ولذلك يشملها النسخ الاحتياطي العام.
- التحديث متوافق مع بنية النسخة الأولى؛ يمكن استيراد ملفات JSON السابقة من قسم «التقارير».
- ملف JSON قابل للقراءة لأي شخص يحصل عليه. احفظه في مكان آمن؛ **لا تخزن هويات العملاء، كلمات السر، نسخ الصكوك الخاصة، البيانات المالية السرية، أو مستندات حساسة في هذا النموذج المحلي أو مستودع GitHub عام**.
- برنامج «متعدد الملاك» من حيث **نمذجة ملكيتهم وحصصهم**؛ لكنه **ليس متعدد الحسابات أو متزامنًا بين أجهزة عدة** حتى يضاف خادم، وتسجيل دخول ومصادقة وصلاحيات وتدقيق مؤمن وقاعدة بيانات.
- سجل الموافقات والحركات المعروض قابل للتعديل من جهاز المستخدم وليس إثباتًا جنائيًا للأحداث، ولا يمثل توقيعًا إلكترونيًا موثقًا.

## نطاق الاستخدام النظامي

المنصة أداة إعداد ودراسة وليست عقد تأسيس، أو نقل ملكية، أو اعتمادًا محاسبيًا، أو تقييمًا ماليًا مستقلًا، أو حكمًا بصحة المشاركة/المضاربة. نسب الحصص الاسترشادية **لا تصبح ملكية معتمدة** بمجرد الحساب، ولا تتحول إلى ملكية رسمية حتى بعد تسجيل «اعتماد داخلي». يجب مراجعة صكوك الأصول، أصحاب الصلاحية، نطاق النشاط، أهلية المستثمرين، الأنظمة وشروط التراخيص مع المختصين.

## مصدر الفكرة وحقوق الكود

هذا مشروع برمجي أصيل مستقل باسم صفوة، يطبق أنماطًا عامة من التنظيم وحساب الشراكات. **لم يُنسخ الكود المصدر لمنصة SHARAKAH**، لأن المستودع العام الخاص بها لا يعرض ترخيصًا يجيز النسخ والتعديل وإعادة التوزيع. لا تمنح هذه الحزمة ترخيصًا لاستعمال شعار نايف أو أي من محتوياته.

لا تنشر أي بيانات حقيقية في المستودع. يُفضّل تقرير سياسة ترخيص كود صفوة قبل جعله مفتوح المصدر.
