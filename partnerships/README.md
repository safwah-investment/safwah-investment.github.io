# صفوة 3.0 | منصة الاستثمار والشراكات والحوكمة

الموقع المنشور: https://safwah-investment.github.io/partnerships/

نسخة أصلية مستقلة لهوية صفوة؛ **لا تستخدم كود مشروع نايف SHARAKAH أو شعاره**. تعمل كواجهة عربية RTL على GitHub Pages، مع وظائف محلية قابلة للاستخدام دون حساب أو مفاتيح خدمة.

## الوظائف

- ملفات ملاك الشركة والملكية المباشرة وغير المباشرة المعلنة بمستوى واحد.
- سجل ملاك الأصول والفرص الاستثمارية والعمولات والقرارات والتصويت المرجّح وفق لقطة الملكية.
- استوديو الشراكات بستة مسارات: مشروع تشغيلي، صفقة تجارية، ناشئ، دخول مستثمر، مضاربة، وإعادة تنظيم. مراحل التعريف، والأطراف، والسجل المالي، والحصص، والحوكمة، والبدائل، والتنفيذ.
- **جديد:** ضمن الحوكمة ثلاث مجموعات سجلات مستقلة: الدور ومقابله وأثر توقفه، الحقوق في العلامات والأنشطة والفروع، وجداول صلاحيات التصرف والتوقيع وحدود المبالغ.
- **جديد:** لوحة فحص الجاهزية تلتقط مجموع الملكية غير المكتمل، فجوات المستفيد الحقيقي، ملكية الفرص غير المحددة، ومستندات لم تراجع.
- **جديد:** مساعد صفوة محلي لشرح الحسابات، ومراجعة المخاطر والمراجع الرسمية، وخطة العمل. يجيب عن بيانات المتصفح الحالية ويعلن أنه محرك قواعد لا نموذج ذكاء اصطناعي خارجي.
- **جديد:** الإملاء الصوتي وقراءة الرد عبر إمكانات المتصفح عند توفرها، بعد تفاعل المستخدم فقط.
- **جديد:** تجهيز اتصال اختياري مع Gemini عبر Supabase Auth + Edge Function. لا يعمل دون مفتاح GEMINI_API_KEY وتهيئة البريد؛ لا يُرسل الملخص إلى النموذج إلا بعد تسجيل الدخول واختيار الوضع السحابي وتحديد خانة الموافقة.
- التقارير Word وHTML وJSON وCSV والطباعة PDF عبر المتصفح.

## تشغيل محلي واختبار

```bash
python -m http.server 8000
# افتح http://localhost:8000/
node --test tests/*.test.cjs
python tests/browser_checks.py
python tests/browser_v3.py
```

لا حاجة إلى npm install للحسابات الأساسية. يعمل التثبيت كتطبيق PWA على HTTPS أو localhost.

## حفظ البيانات والحدود

المحتوى الحالي مخزن في `localStorage` لهذا المتصفح فقط؛ **لا يوجد تزامن متعدد الحسابات أو مشاركة بيانات بين الملاك**. يتعين تنزيل نسخة JSON احتياطية قبل تغيير الجهاز أو مسح بيانات المتصفح. لا تحفظ عقودًا غير منشورة أو أرقام هويات أو بيانات مالية سرية في هذا الإصدار المحلي. المساعد المحلي لا يرسل البيانات خارج الجهاز، لكنه ليس استشارة قانونية أو تقرير تحقق مستقل.

## إعداد المساعد الذكي الخارجي

تم إنشاء Backend مستقل تحت `backend/supabase/functions/safwah-advisor/` ليتصل بواجهة صفوة دون مفاتيح سرية في GitHub. يعمل بخاصية `verify_jwt=true`، ويتطلب Supabase Auth لبريد مؤكد، وتحققًا إضافيًا من قائمة بريد مخوّل. هو **ليس** Gemini Live صوتيًا؛ الاتصال الخارجي نصي فقط، والصوت المستخدم هو ميزات التعرف والنطق في المتصفح.

1. في لوحة Supabase الخاصة بمشروع صفوة، أضف `GEMINI_API_KEY` كسر لا يظهر في الكود العام. تحقق من تفعيل الفوترة وسياسات تكلفة الاستخدام.
2. ضمن Auth → URL Configuration، اسمح بعنوان إعادة التوجيه `https://safwah-investment.github.io/partnerships/` وفعّل Email OTP المناسب.
3. أضف البريد الإلكتروني الموثق للملاك المخوّلين (إذا لزم) ضمن `SAFWAH_AI_ALLOWED_EMAILS`، مفصولًا بفواصل. بريد مدير حساب صفوة مرتبط مسبقًا بكود الخادم بعد التحقق من هويته عبر Supabase Auth، ولا تستخدم بيانات `user_metadata` للصلاحيات.
4. ادخل إلى صفوة، وافتح «مساعد صفوة» → «الربط الاختياري» → اطلب رابط الدخول بالبريد، ثم فعّل موافقة مشاركة الملخص والوضع السحابي.
5. **قبل الإتاحة العامة:** أضف حد استخدام عالمي دائم، ومراقبة تكلفة، وسجل أخطاء منزوع الهوية؛ الحد المؤقت بالخادم ليس حدًا عالميًا في الأنظمة الموزعة.

الواجهة تستخدم مفتاح Supabase **النشري** فقط، وهو مفتاح عام منخفض الامتياز؛ لا يوجد مفتاح خدمة أو مفتاح Gemini في ملفات المستخدم.

## حقوق المرجع

الاستفادة هنا من المبادئ المهنية العامة: التفريق بين المساهمات والملكية والحقوق، والقرارات والبدائل، والمراجع النظامية. لم يُنسخ كود نايف المحمدي غير المرخّص. راجع النصوص النظامية الحالية قبل استخدامها في وثيقة ملزمة.
